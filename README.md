# Smart BMS — Android app downloads

Smart BMS is the point-of-sale app for shops on the BJP Technologies BMS platform:
sell (even without internet), print receipts, manage stock, customers and credit,
and see your reports — all from your phone.

## Download
Get the latest version from **[Releases](https://github.com/MussaJabir/duka360-app-releases/releases/latest)**
and download the `.apk` file.

## Install (Android)
1. Download the `.apk` on your Android phone.
2. Open it. If asked, allow your browser or file app to **install unknown apps**.
3. Tap **Install**, then open **Smart BMS**.
4. Sign in to your shop, or create a new business.
